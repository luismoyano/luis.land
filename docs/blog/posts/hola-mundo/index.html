Hola, esto es el dev vlog

Este es el primer post del dev vlog de luis.land.

Aquí voy a escribir sobre cosas que construyo, bugs que encuentro, ideas que no sé si van a funcionar y procesos que me resultan interesantes.

No hay formato fijo. A veces será largo, a veces tres líneas.

El setup de este blog es un buen ejemplo de lo que va a ir aquí. Hugo, sin framework de frontend, viviendo en un subdirectorio de una landing hecha a mano. Sin npm, sin build step de JavaScript, sin dependencias absurdas. Solo Markdown y un tema que pesa menos de 200 líneas.

Empezamos.
